# BUG-12: HTML тэмдэгттэй гарчиг entity болж харагдаж хайлт зөрнө

Төрөл: GUI / өгөгдөл дүрслэх
Орчин: Уншлагын жагсаалт v2.0, Debian GNU/Linux 13.7, Node.js v20.20.2; session-ийн browser: Codex in-app browser (engine version харагдаагүй), 2026-11-26.
Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асааж, анхны 3 номтой төлөвөөс эхэлнэ.
## Дахин гаргах алхам
1. Серверийг шинээр асаана.
2. Гарчигт `A & B` гэж өгөөд бусад талбарыг бөглөж ном нэмнэ.
3. Жагсаалтын утгыг ажиглаад хайлтад яг `A & B` гэж оруулна.

Хүлээгдэж байсан: Хүснэгт гарчгийг хэрэглэгчийн оруулсан текстээр харуулж, тухайн утгаар хайлт олно.
Бодит үр дүн: UI `A &amp; B` гэж харуулж, `A & B` гэж хайхад мөр олдохгүй. `<b>Book</b>` утга ч `&lt;b&gt;Book&lt;/b&gt;` болж харагдсан.
Ноцтой байдал: Major — special character-тэй номын гарчиг буруу харагдаж, хэрэглэгчийн оруулсан хайлтанд олдохгүй.
Олдсон аялал: Supermodel (GUI), Saboteur (special-character input).

Скриншот файл энэ session-д хадгалагдаагүй; browser screenshot-ийн ажиглалт timestamp тэмдэглэлд бий.
