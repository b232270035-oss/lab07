# BUG-10: Устгасны дараа нэмсэн тухай мессеж гарна

Төрөл: GUI / үйлдлийн санал хүсэлт
Орчин: Уншлагын жагсаалт v2.0, Debian GNU/Linux 13.7, Node.js v20.20.2; session-ийн browser: Codex in-app browser (engine version харагдаагүй), 2026-11-26.
Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асааж, анхны 3 номтой төлөвөөс эхэлнэ.
## Дахин гаргах алхам
1. Серверийг шинээр асаана.
2. Анхны номын `Устгах` товчийг дарна.

Хүлээгдэж байсан: Устгасан тухай эсвэл амжилттай устгасныг илэрхийлсэн мессеж харагдах.
Бодит үр дүн: Номын мөр арилсан ч “Ном нэмэгдлээ” гэж харуулна. Restart-аас дахин эхлүүлэхэд давтагдсан.
Ноцтой байдал: Minor — устгах үйлдэл амжилттай боловч хэрэглэгч буруу мэдээлэл авна.
Олдсон аялал: Supermodel (GUI), delete action.

Скриншот файл энэ session-д хадгалагдаагүй; timestamp тэмдэглэл `session-report.md`-д байна.
