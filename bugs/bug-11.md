# BUG-11: Урт тасралтгүй гарчиг хүснэгтийг дэлгэцээс сунгана

Төрөл: GUI / layout
Орчин: Уншлагын жагсаалт v2.0, Debian GNU/Linux 13.7, Node.js v20.20.2; session-ийн browser: Codex in-app browser (engine version харагдаагүй), 2026-11-26.
Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асааж, анхны 3 номтой төлөвөөс эхэлнэ.
## Дахин гаргах алхам
1. Серверийг шинээр асаана.
2. Гарчигт 180 дараалсан `W`, зохиолчид `QA`, ондоо `2001` оруулаад `Нэмэх` дарна.

Хүлээгдэж байсан: Spec-ийн дагуу ямар ч урттай оролт хүснэгтийг эвдэхгүй, бусад багана ашиглах боломжтой хэвээр байна.
Бодит үр дүн: Хүснэгт контейнероос өргөсөж horizontal scrollbar гарна; зохиолч, он, устгах баганууд харах талбайгаас гарна. Restart-аас давтагдсан.
Ноцтой байдал: Major — урт утгатай бичлэгийн бусад мэдээлэл болон үйлдэл viewport-оос гарна.
Олдсон аялал: Supermodel (GUI), Fed-Ex (урт утга дамжих).

Скриншот файл энэ session-д хадгалагдаагүй; browser screenshot-ийн ажиглалт timestamp тэмдэглэлд бий.
