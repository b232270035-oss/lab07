## Хэсэг E: Дүгнэлт

Charter-д Supermodel (GUI) болон Saboteur (API) аялал сонгосон ч session-ий явцад Couch Potato (хоосон оролт) болон Fed-Ex (өгөгдлийн зам) аялалыг мөн ашигласан. Supermodel хамгийн олон согог өгсөн: нийт номын тоо, оны формат, Устгах товчны өнгө, хайлтын том/жижиг үсэг (BUG-01, 02, 03, 06). Couch Potato аялалаар хоосон оролттой ном нэмэгддэг согог (BUG-05), Fed-Ex аялалаар ижил номыг давхар нэмдэг согог (BUG-07) олдсон. Saboteur аялалаар /old холбоос 500 алдаа өгдгийг (BUG-04) олсон, харин буруу JSON-д 200 OK буцаадаг API согог (BUG-08) session-ээс хойш Windows дээр curl.exe-ээр шалгах үед олдсон. Charter-ээс гадуур олдсон зүйл бол хоосон оролт болон давхардлын согог. Оны хязгаар (1000-2100), хэт урт оролт, тусгай тэмдэгт, үсгийн алдаа зэрэг нь шалгагдаагүй үлдсэн тул дараагийн session-ий charter болно. Playwright автомат тестээр BUG-01, 02, 04, 05, 06, 07, 08 найдвартай баригдах байсан, учир нь эдгээр нь тодорхой текст, тоо, статус кодтой. BUG-03 (өнгө) нь CSS утгыг шалгадаг тест бичсэн тохиолдолд л баригдана. Зөвхөн хүний нүдээр илрэх нь хуудасны ерөнхий харагдац, тоо болон форматын зөрүү байсан. Exploratory тест нь урьдчилан бичээгүй сценарийг олдог, автомат тест нь олдсон согогийг дахин шалгахад хэрэгтэй гэдгийг ойлгов.
