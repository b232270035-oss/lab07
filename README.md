# Lab 07: Exploratory Testing and SBTM

- Оюутан: Дэлгэрмаа
- Систем: Debian Linux
- Repo: https://github.com/b232270035-oss/lab07.git

## Дүгнэлт
Session-Based Test Management (SBTM) болон эрэлхийлэх туршилтын аргыг ашиглан 60 минутын хугацаанд аппликейшныг шалгаж үзлээ. Туршилтын явцад дэлгэцийн харагдац, өгөгдлийн баталгаажуулалт, серверийн ажиллагаатай холбоотой нийт 7 алдааг илрүүлж баримтжуулсан.

Илэрсэн гол алдаанууд:
1. Нийт номын тоо зөрүүтэй
2. Оны формат таслалтай харагдаж байна
3. Устгах товч ногоон өнгөтэй байна
4. /old холбоос 500 алдаа зааж байна
5. Хоосон утгатай ном нэмэгдэж байна
6. Хайлт дээр том жижиг үсэг ялгаж байна
7. Давхардсан ном нэмэгдэж байна
